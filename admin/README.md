# Admin web - PWOP

Objectif
Un espace administrateur simple (React) pour :
- Voir et gérer les clients
- Voir et gérer les demandes de collecte
- Gérer les paiements et marquer les paiements comme reçus
- Gérer les employés (création, assignation)

Pages recommandées
- Dashboard (KPIs: demandes aujourd'hui, paiements en attente)
- Clients
- Demandes de collecte (filtrables par statut et date)
- Paiements
- Employés

Auth
- Authentification basée sur JWT.

Déploiement
- Héberger le backend (Heroku, Railway, ou VPS), base de données PostgreSQL.
- Héberger l'admin sur Vercel ou Netlify.
